# Sales & Revenue Analysis Dashboard

## Project Overview
This project analyzes sales and revenue data using Power BI and provides business insights through interactive visualizations.

## Features
- Total Sales KPI
- Total Profit KPI
- Product-wise Sales Analysis
- Category-wise Sales Analysis
- Region-wise Sales Distribution
- Interactive Filters and Slicers

## Tools Used
- Power BI Desktop
- Microsoft Excel
- GitHub
